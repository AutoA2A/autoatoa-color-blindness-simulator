# 色盲视觉模拟器

## 网站简介
色盲视觉模拟器是一个旨在帮助人们理解色盲人士视觉体验的在线工具。该网站通过模拟不同类型的色盲，帮助用户直观地了解色盲人士如何看待周围的世界，从而促进对色盲的理解和包容。

## 页面与功能
网站包含以下5个页面：
1. **首页**：介绍色盲视觉模拟器的目的和功能，提供快速入口让用户直接体验模拟器。
2. **模拟器页面**：核心功能页面，提供色盲视觉模拟器。用户可以上传图片或使用默认图片，选择不同的色盲类型（如红绿色盲、蓝色盲等），实时查看模拟后的图像。
3. **关于色盲**：提供关于色盲的基础知识，包括色盲的定义、类型、成因和影响，帮助用户更好地理解色盲。
4. **使用指南**：详细说明如何使用色盲视觉模拟器，包括图片上传、色盲类型选择等操作步骤。
5. **联系我们**：提供反馈和联系方式，鼓励用户分享他们的体验和建议。

## 多 AI 协作与验收
本项目采用多 AI 协作的方式完成，涉及的 AI 模型包括但不限于图像处理模型、文本生成模型等。协作流程如下：
- **需求分析**：由 AI 辅助分析项目需求，确定网站功能和页面结构。
- **内容创作**：利用文本生成模型创作网站文案，包括页面内容、按钮文本等。
- **图像处理**：使用图像处理模型实现色盲视觉模拟功能，根据不同的色盲类型对图像进行处理。
- **前端开发**：通过 AI 辅助前端代码生成，实现网站的页面布局和交互功能。
- **测试与验收**：多轮测试确保网站功能正常，页面兼容性良好。AI 辅助测试工具用于自动化测试。
