# 多AI协作项目：色盲视觉模拟器

## 网站简介
“色盲视觉模拟器”是一个专注于提升网页无障碍体验的在线工具。该网站旨在通过实时模拟不同类型的色觉障碍（如红绿色盲、蓝黄色盲、全色盲等），帮助设计师、开发者和内容创作者直观地理解其作品在色觉障碍用户眼中的呈现效果，从而推动更具包容性的界面设计。项目采用模块化架构，共包含 **8个独立页面**，由多个AI智能体协同完成内容生成、交互设计与代码实现，确保功能的完整性与专业性。

## 页面与功能
网站包含以下八个核心页面，形成完整的工作流：
1.  **首页 (index.html)**：项目介绍、核心功能展示及导航入口。
2.  **模拟器核心页**：用户上传图片或指定URL，实时应用多种色盲滤镜进行对比预览。
3.  **色盲类型详解页**：图文并茂地科普不同色觉障碍的成因、分类及视觉感受。
4.  **设计指南页**：提供基于WCAG标准的色彩搭配、对比度检测与UI设计最佳实践。
5.  **工具集页面**：整合对比度计算器、色彩拾取器等辅助小工具。
6.  **案例展示页**：展示经过色盲优化的网页设计前后对比案例。
7.  **关于页**：项目团队（AI协作体）介绍、项目理念与致谢。
8.  **反馈与联系页**：集成简单的表单功能，收集用户意见。

## 多AI协作与验收
本项目的核心创新在于**多AI协作开发模式**。项目并非由单一AI生成，而是模拟了“产品经理”、“UI/UX设计师”、“前端工程师”和“测试工程师”等不同角色的AI智能体：
*   **协作流程**：由需求AI进行功能拆分，设计AI生成页面原型与色彩方案，工程AI负责代码实现与API调用，测试AI进行功能验证与无障碍兼容性检查。
*   **验收标准**：所有页面需通过**Lighthouse无障碍审计**、**响应式布局检查**及**核心功能测试**。每个AI交付物都需经过其他AI的交叉验证，确保代码质量、设计一致性与用户体验的流畅性，最终整合为可部署的静态网站。

## GitHub Pages 部署与访问
项目采用纯静态网站技术栈（HTML、CSS、JavaScript），可直接通过GitHub Pages进行部署和托管。
*   **入口文件**：网站统一入口为根目录下的 `index.html` 文件。
*   **部署流程**：代码仓库推送到GitHub后，在仓库的“Settings”页面启用GitHub Pages功能，选择主分支（如`main`或`master`）的`/ (root)`目录作为源。部署后，GitHub将提供一个公开的访问URL。
*   **访问方式**：用户可通过生成的URL（格式通常为 `https://<用户名>.github.io/<仓库名>/`）直接访问网站，无需搭建本地服务器。此部署方式确保了项目的可访问性、版本管理的便捷性以及零成本的长期维护。
